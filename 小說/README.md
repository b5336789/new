# 《紅塵問道錄》

> 一部後宮仙俠長篇小說 · 目標篇幅約 200 萬字

## 一句話簡介

家門遭滅的少年沈墨,得殘卷《紅塵問道經》,踏上一條前無古人的「情之大道」——
旁人視七情六慾為修行大忌,他偏要在這紅塵萬丈中問鼎仙途。

## 核心賣點

- **獨特修煉設定**:以「紅塵劫/情之一道」為主角金手指。世間修士斬七情、絕六慾以求大道,
  主角反其道而行,每一段刻骨銘心的緣分,都化作他道基的一塊基石。後宮元素由此成為
  世界觀與功法的內在邏輯,而非無根之水。
- **成長爽感**:由廢入聖,弱小到無敵的經典骨架,配合「情劫渡人」的反套路。
- **群像紅顏**:每位女主性格、立場、際遇各異,並非花瓶,而是各自背負因果、推動主線。
- **大格局**:從一城一宗,寫到九州、域外、仙界,層層遞進。
